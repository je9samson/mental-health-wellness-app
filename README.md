## 📝 Project Description
This is a wellness awareness website built with Vue 3. It is designed to help users manage their mental health through breathing exercises, wellness tips, and AI-powered support.

## 📍 Pages Created
* **Home:** The main landing page.
* **Breathing:** Interactive guides for relaxation.
* **Wellness:** A collection of tips for mental health.
* **AI Support:** A placeholder for the upcoming AI chat feature.

## 🛠️ How to Run the Project
1. Clone the repo
2. Run `npm install`
3. Run `npm run dev`
